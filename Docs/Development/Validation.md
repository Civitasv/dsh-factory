# Validation

## Local checks

```bash
pnpm install
pnpm typecheck
pnpm lint
pnpm test
```

Run `pnpm check` for the full baseline.

## CI

GitHub Actions is the CI source of truth. The baseline workflow runs on:

- pushes to `master`;
- all pull requests.

The repository intentionally does not use CNB.

## Lockfile bootstrap

The repository is initially created through API tooling without registry access, so no generated `pnpm-lock.yaml` is fabricated by hand. CI uses `pnpm install --no-frozen-lockfile` until a real lockfile is generated by pnpm and reviewed/committed.

After the first lockfile is committed, change CI to `pnpm install --frozen-lockfile`.

## Green definition

A change is Green only when applicable GitHub Actions checks have actually passed. Local or agent assertions are not substitutes for recorded validation.
